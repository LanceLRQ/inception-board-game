# 现代暗色牌桌与 2.5D 交互原型

日期：2026-11-02。用户已选择「现代暗色牌桌＋2.5D」方向，并要求桌面与手机原型、原版卡片、完整文字、选牌／出牌／掷骰演示。本文记录本次交付，前期讨论见 [UI 现代化讨论记录](../../discussion/2026-11-02-ui-modernization.md)。

## 打开与体验

- [自适应牌桌](index.html)：桌面、平板、手机共用入口，可以直接用浏览器打开本地文件。
- [手机预览框](mobile.html)：在桌面浏览器中以 390 × 844 的画面操作；手机打开时占满屏幕。
- [教程独立预览](http://127.0.0.1:13001/#guide)：直接打开游戏教程说明书，也可在本地 `index.html` 地址末尾添加 `#guide`。
- 本次本机预览服务：[桌面](http://127.0.0.1:13001/)／[手机预览框](http://127.0.0.1:13001/mobile.html)。服务停止后可按下面命令重新启动。127.0.0.1 仅当前电脑可访问，不是手机公网地址。

在本目录运行：

```sh
python3 -m http.server 13001 --bind 127.0.0.1
```

推荐体验顺序：

1. 默认不选牌、隐藏操作按钮；点选手牌，观察原卡抬起、边框和文字说明变化，手牌下方出现「查看解析」与出牌按钮。再次点击同一张手牌取消选择。
2. 选中 SHOOT，点击「打出 SHOOT」，选择暮雨并确认，观察卡牌飞入出牌区。
3. 点击「掷骰」，观察立体骰子转动、落定为 4 点，再选择相邻层；目标位置随之更新。
4. 点右栏原卡或手牌下方「查看解析」，打开完整解析；右栏底部「游戏教程说明书」（手机为手牌标题旁的「教程」）打开分类图鉴与规则全文。角色牌、梦境牌和已打出的牌也能点击阅读。
5. 重置后试用解封、梦境穿梭剂、KICK、梦境窥视。手机五张手牌同时显示；超过五张时换行排列。顶部可以独立体验掷骰、切换减少动效、重置。
6. 桌面点击层数卡翻看金库；手机点击层数横条打开金库原卡与全文。未查看只显示原版背面，使用梦境窥视后显示内容并标注“仅你可见”。
7. 点击“局面演示”选择“金币开启前”或“秘密开启前”，再打出解封，观察心锁归零和金库公开；秘密公开后仍可翻牌和阅读。
8. 选择“弃牌阶段”，从 7 张手牌中点选 2 张，在相同操作区点击「弃掉所选 2 张」。少选或多选时不可提交；取消全部选择则隐藏按钮。

手机工具栏的三个图标依次为掷骰、减少动效、重置，保留可访问名称与 44px 点击区。手机竖屏同时展示四层横条、玩家头像、骰子和完整手牌网格；横屏为梦境横条与手牌并排。盘面、层数和手牌不再各自滚动；内容超过可用高度时使用整页纵向滚动。无需悬停才能查看说明或出牌。

## 范围与演示假设

这是独立交互原型，没有改动正式游戏源码、依赖、路由、服务器或规则引擎。固定为六人样例局面，昵称和手牌是演示数据，不读取真实对局。

五种行动牌用于演示交互：SHOOT 限同层其他玩家，由原型代目标掷骰并固定为 4 点；解封假设无人抵消；穿梭和 KICK 展示层数变化；梦境窥视使对应金库内容仅对本人可见。心锁归零公开金库，打开秘密后显示盗梦者胜利并禁止继续出牌。另提供独立弃牌场景，从 7 张弃至 5 张，包含同名牌以验证独立选取。没有实现完整回合、响应链、角色技能发动、AI、联机、其他胜负分支、音效或其他骰点分支。界面明确标示固定骰点。角色和梦主的完整规则可读，不表示其能力已在演示状态中执行。

图鉴覆盖项目全部 103 个原版牌面（含背面、双面角色的另一面与配置卡），分 8 个类别；另有 9 章原版规则全文。图鉴介绍卡种，不显示本局隐藏牌分布。

## 桌面层数面板

按反馈，牌桌正面不再显示完整原版层数卡，而是由原图底纹裁片、透明数字图片和四角控件组合。说明书中的原卡保持完整展示。

- 四层分别使用各自原卡的无字底纹裁片，上下镜像衔接后铺底；保留原始 RGB，不做 CSS 染色或生成补绘。数字背后被遮住的底纹无法直接恢复，所以使用原卡上方无字区域，而不是声称还原整张底纹。
- 数字从各自原图抠出，背景透明，保留原始字形和可见像素颜色。8 个素材均为无损 WebP，合计 759,758 字节；裁切坐标和方法见 [原卡提取记录](assets/layers/README.md)。
- 数字使用等比缩放的图片，水平和垂直居中。面板高度与宽度独立，不再绑定完整原卡比例。
- 四角控件统一保留 14–20px 内边距；上方头像单行横滑，保留骰子位置；中间数字与底部状态区分开。翻面的金库原卡按用户要求使用 cover 居中裁切，铺满容器并适度放大去掉黑边；四角控件覆盖在其上，完整卡图仍可在解析与说明书中查看。
- 桌面四列自适应，过窄时保留最小 156px 面板宽度并横滑；重绘和屏幕尺寸变化时将当前层移至可见区域。手机使用下文的独立横条布局。
- 本轮只改 `app.js` 的层数正面与居中逻辑、`styles.css` 的面板样式以及素材说明；复用翻牌、权限和全文弹层。没有改正式游戏、规则状态或原卡文件。

## 层数区域与信息可见性

用户确认沿用原规则：使用「梦境窥视」查看金库，梦主可以在此过程中发放贿赂牌，贿赂牌本身不用于查看。原型固定梦主放弃派发贿赂牌；金币开启后也跳过梦魇与贿赂响应，不模拟这些完整机制。

- 牌桌使用独立的深色绒面 WebP，城市背景不进入该区域；顶部信息合为一行。
- 心锁骰子放在每张卡片右上角的半透明灰色底上，中央独立层数数字不被遮挡。删除重复的层数标题和“你在此”。只保留骰子，不显示“心锁”文字；归零显示 0，无障碍名称仍说明剩余心锁数量。
- 牌面左上为头像，右上为骰子，左下为查看状态，右下为说明按钮；中央数字留空。你的头像与所在卡片为金色描边，头像小点跟随当前行动者。头像较多时在左上区域内部滚动。其他人的隐藏阵营不对外标示。
- 自建 tooltip 在鼠标悬停或键盘聚焦时显示玩家名、角色、层数、手牌数及当前状态；Esc、移出、失焦、滚动时关闭。手机第一次点按显示 tooltip，再次点按同一头像打开完整角色原卡。
- 默认未知金库的反面 DOM 只使用原版背面，不隐藏一张已带秘密图片的正面。窥视后本人视图为 private，其他玩家视图仍为 hidden；开启后为 public。看见秘密不触发胜利，公开打开秘密才结束。
- 秘密终局以牌桌内横幅和公开秘密牌展示，不用弹窗遮住终局；其他未查看且未开启的金库继续保留背面，出牌被禁用，翻牌与阅读仍可用。
- 局面演示还包括“窥视后”与“迷失层”；后者将已死亡的星河显示在独立的待复活区域，普通行动不能选中他。

这里的私有／公开视图是独立原型的呈现验证，固定金库数据仍在本机演示状态里，并非生产环境的信息安全边界。正式联机需沿用现有服务端按玩家裁剪的状态。六人样例固定第三层为秘密，其余为金币；演示切换不是正式游戏动作。

## 设计取舍

### 生成素材补充

按用户追加要求，使用内置 image_gen 生成了折叠城市梦境背景与黄铜材质。城市场景用于页面底层和弹层标题区，牌桌改用单独生成的深色绒面材质；黄铜纹理用于出牌、确认、掷骰等主操作。次要按钮、全文阅读区和手牌区保留干净底色，原版卡图不变。Lucide 继续承担可识别的操作图标，不以生成图代替按钮文字。

所有网页新增位图均为 WebP：桌面场景 52,984 字节、手机场景 18,924 字节、共享按钮纹理 5,160 字节。初次环境素材桌面约 56.8 KiB，手机约 23.5 KiB；本轮另外加入 1,164 字节的独立牌桌材质；手机按媒体查询使用较小场景，多个组件共享同一 URL。原稿、最终提示词、导出参数见 [素材记录](assets/environment/README.md)。没有新增实时渲染或持续背景动画。

### 布局与操作

结合 ui-ux-pro-max 的操作与可读性检查、design-taste-frontend 的应用界面规则。方向为 True-black flat，抽签 seed 为 493494876，无重抽；保留石墨黑、暖金与系统中文字体。构图来自游戏的四层梦境、在场角色、手牌与牌堆，原版卡图承担主要视觉内容。

- 桌面：左侧玩家，中间梦境与手牌，右侧原卡靠右、摘要文字环绕；点原卡打开完整解析。右栏内容独立滚动，教程入口固定在右栏底部。
- 手机：四层梦境纵向排列为横条，原图数字、玩家、金库状态与骰子在同一行；手牌按屏幕宽度完整排布，出牌操作紧随手牌，原卡与完整文字使用阅读弹层。
- 色彩：底色 `#111213`、表面 `#1a1b1d`、正文 `#f1f2f3`、辅助字 `#b3b3ae`、选牌强调 `#d5b276`。梦境颜色来自原卡自身。
- 字体：沿用系统中文无衬线；全文 16px，主要操作 13–14px；手机主要标签与牌名使用 12px，页脚及牌堆辅助文字为 11px；后续真机可读性仍需验证。
- 动效：CSS 透视、旋转、位移与 Web Animations；骰子六面用 CSS 3D。没有持续 WebGL 场景、实时灯光或粒子系统。
- 状态：选中、禁用及原因、出牌中、等待目标、待掷骰、待移动、手牌用尽、重置均有对应反馈。支持键盘焦点、原生弹层、Esc 返回和实时状态文字。

初版纯色截图复核（不是用户研究）：视觉 7.5/10、易用性 8/10、特色 7/10、内容完整性 8/10。追加生成素材后，背景空间感和主按钮材质更明显；保留原有操作位置及全文区域，通过实际截图检查，没有将材质变化视作可用性提升的证明。音效与更强演出仍未验证。

## 手牌操作与弃牌演示

- 出牌与弃牌操作统一放在手牌下方。默认、取消所有选择、重置和出牌结算完成后隐藏按钮；保留操作区域高度，避免选牌时整排手牌跳动。出牌阶段单选，弃牌阶段多选，再次点击已选牌即取消。
- 右栏只显示选中卡的原图、摘要、目标、时机和教程入口，不再承担出牌操作。手机通过手牌下方「查看解析」读全文，教程入口固定在手牌标题旁。
- 出牌后不自动选中下一张牌。SHOOT 尚待掷骰或移动时，操作区保留「继续掷骰」或「选择移动层」，让收起弹窗后仍能继续结算。
- 弃牌场景按 [弃牌阶段规则](../../../manual/03-game-flow.md) 保留 5 张：7 张选 2 张，仅数量准确才允许提交。弃牌不发动卡牌效果；完成后清空选择、更新弃牌堆与手牌数。同名牌按手牌位置独立选取和消耗。
- 浏览器实测选中／取消、选错弃牌数量、重复牌选取、弃牌完成、SHOOT 收起后继续与结算后隐藏。页面检查覆盖 360×640、390×844、768×1024、844×390、1024×768、1440×900；手机手牌现按下文的网格完整排列，按钮留在手牌下方。

## 教程固定窗口与内部滚动

原布局随章节、搜索结果和卡牌数量改变弹层高度，居中后顶部也随之移动；规则分类还会隐藏搜索框，卡牌解析则叠加第二个弹层。本轮改为固定外框内的目录与阅读区，正文多少不再决定窗口位置。

- 桌面使用分类、目录、正文三列。分类与搜索栏位置固定，长目录和正文分别滚动；窄屏目录较长时分类本身也可滚动。弹层最高 820px，视口更矮时自动收进可用高度。
