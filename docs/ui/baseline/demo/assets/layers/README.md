## 底纹

每张原卡取 `674×205+35+35` 的上方无字区域，避开外框、数字及数字阴影。保存 674×205 裁片，CSS 按面板宽度等比缩放并上下交替镜像铺底，保持细纹密度；同层只加载一张纹理，不在文件内重复保存像素。不是复原数字背后不可见的整张底纹；每一像素均来自同一张原卡，未调色，也没有 AI 补绘。镜像用于衔接重复边缘。

ImageMagick 导出方式：

```sh
magick ../dream_1.webp -crop 674x205+35+35 +repage -define webp:lossless=true texture-1.webp
```
