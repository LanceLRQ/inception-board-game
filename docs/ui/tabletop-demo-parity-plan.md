## 目标与范围

最终视觉基准为 [现代暗色牌桌 demo](../_internal/ui-demo/modern-tabletop/index.html) 及其 `styles.css`、`mobile.css`、`guide.css`、`app.js`；该目录目前被 Git 忽略，冻结基线时需保存可复现的版本、素材清单与截图。对局的布局、字号、字体、颜色、素材铺法、组件和交互节奏完整对齐 demo，撤回上次“保留旧主题配色”的决定，旧皮肤不能覆盖新对局。大厅、登录、房间等待页不在本次重做范围。

保留 `MatchSource`、`MatchController`、真实引擎、服务器权限裁剪、随机骰点和网络接口。demo 的模拟玩家、固定骰点、重置／轮转／局面演示按钮不进入正式游戏；抽牌、结束行动、技能、复活、应答、聊天、重连和举报等正式功能按同一视觉规则承载。完整原卡继续使用正式素材与版本哈希，层数使用原图提取的底纹和透明数字，新增位图保持 WebP。
