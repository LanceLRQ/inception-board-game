## 完成标准与执行约束

**视觉还原与功能回归必须同时通过。** 每一步完成后记录修改文件、截图／操作证据、测试命令和未解决项；不得用编译通过、测试总数或“没有横向溢出”替代 UI 一致性验收。测试应验证真实交互与分类可达性，不能只验证静态数据存在。正式机制需额外组件时沿用 demo 风格并在对照清单中说明，不恢复旧界面。

本方案以本次用户“完全按照 UI demo”要求为准，取代 [首次接入记录](tabletop-integration.md) 中关于视觉完成度和保留旧配色的结论。当前工作区已有上一轮未提交的改动，实施时先核对现状，不执行整树回退，不覆盖无关修改；由主进程开发和复核，不派 subagent。用户已授权先提交当前代码、同步看板，并按顺序实施；每阶段验证完成后独立提交，不执行 push。
