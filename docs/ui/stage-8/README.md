## 实际操作

- 本地真实引擎：新开四人局，抽到三张手牌；选 SHOOT、选目标后仍为三张，点击确认后减为两张并清除选择；引擎返回 Player 2 掷出 6 点，见 [确认出牌](local-confirmed-play.webp)。未修改骰点或游戏规则。
- 联机：独立内存测试服务，两个隔离来源（localhost 与 127.0.0.1）的浏览器标签分别建档为“牌桌验收甲／乙”，创建同一房间、补 Bot、开局。桌面与手机使用相同服务端 match ID；实际点击抽牌、结束行动、弃牌及掷骰流程。并非 fixture 模拟联机。
- 进行中刷新手机页：match URL 不变，恢复回合和界面，无 remote-error。完成后双方都显示“梦主获胜”，无默认弹层，见 [甲终局](online-final-0.webp)、[乙终局](online-final-1.webp)。
- 终局默认收起最后一次骰子结果；点击“查看上次掷骰”显示真实 3 点，收起后恢复牌桌；点击结算可见返回大厅与另一真人的举报入口，见 [联机结算](online-outcome.webp)。此次未向其他真实用户发出举报。
- 固定场景补查：[角色技能](skill.webp)、[复活选牌](revive.webp)、[贿赂派发入口](bribe.webp)、[梦魇决策](nightmare.webp)、[SHOOT 应答](response.webp)、[多人掷骰等待 1/5](multi-dice.webp)。窗口内部滚动，390px 页面无横向溢出。
- 阶段 3–7 的翻牌权限、轮转、同名弃牌、选牌旋转保留、教程分类与滚动检查仍有效；没有更改引擎或服务端权限裁剪。
